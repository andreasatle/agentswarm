Switch mdconv.to_html to the new pipeline (mdconv/blocks.py, mdconv/inlines.py, mdconv/html.py) gradually, one kind of block at a time, the way the spec's appendix "A parsing strategy" in docs/spec.md describes it: start with paragraphs, then the other leaf blocks (thematic breaks, headings, code blocks, HTML blocks), then container blocks (block quotes, list items, lists). At every step every example that passes now must still pass; keep the old code path for the kinds not yet switched, and remove it only when nothing uses it. When all kinds are switched, container blocks must nest (lists in block quotes in lists).
